# ECON Commons · 下载

ECON Commons 网站的下载文件。网站通过分享链接打开时不能直接保存文件，所以学习包放在这里的 Releases 里：

- **Lite**：每周学习包（`lite-<课程>-<周>-zh.zip`）。下载后交给你的 ChatGPT 或 Claude，粘贴包里的开课指令。
- **Pro**：前置资料包（`econ-commons-pro-<课程>-<语言>-<版本>.zip`）。只需下载一次，用来配置 Project；之后每周用你自己从 Moodle 下载的课件让 AI 备课。

不包含任何大学课程原件（syllabus、slides 等），请自己从 Moodle 下载。
